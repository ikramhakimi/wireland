# Templates

Each file starts with: page, URL, date, and which files it was built from.
IDs (`Q1`, `C2`, `F3`) let later files cite earlier ones.

## 01-audit.md

```md
# Audit — <page>
URL · date · read at 390 first

## Goal
- Job / KPI: …
- Primary action: … → <destination>
- Traffic source and its promise: … (or: unknown — question below)
- Must stay: …

## Copy in order
1. Hero — H: "…" · Sub: "…" · Buttons: "…"
2. <section> — H: "…" · Button: "…"

## Five buyer questions
| # | Question            | Answer, quoting the page | Note                          |
| - | ------------------- | ------------------------ | ----------------------------- |
| 1 | What is it?         | "…"                      | category words / clear / not on the page |
| 2 | Who is it for?      |                          |                               |
| 3 | What do I get?      |                          |                               |
| 4 | Why believe it?     |                          |                               |
| 5 | What do I do next?  |                          |                               |

## Objections
| Objection | Answered? | Where |

## Confirmed facts (F1…)
Facts the page or docs confirm, usable as sources later.

## Questions for the user
```
